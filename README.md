# Infans · 小秘书

作者手写自述：并没有多大创新，也是用AI整合的项目，不过并不是概念型产品，诸多机制已多次迭代运行良好，我已深度获益。如果不好可能是目前开源项目阉割了大约35%。本项目我觉得最大的价值，是能够降低自己的做事的启动成本和任务切换成本，降低生活琐事对自己精力的消耗，其他都是好玩的添头罢了。

一套跑在你自己电脑上的本地助手框架。

Infans 把「一个私人助理该替你盯的事」摊成一个网页工作台：项目和待办、日程、身心状态、每天的资讯、语言学习、知识地图、藏书影音、账目，还有一排小工具。工作台右边常驻一位秘书，随时可以一对一说话。

所有内容都是你自己目录里的 Markdown 和 JSON 文件，服务只监听本机回环地址，不用注册账号，不往云端传。

这个仓库提供核心参考实现、技术说明和示例资源。模型、外部服务和手机端能力，按你自己的环境配置或扩展。

## 先说清楚三件事

1. **这是框架，不是装完即用的成品。** 聊天默认不接任何模型，界面会明写「模型未配置」。要接你自己的模型，需要改一处适配代码，不是填一条密钥就能用。
2. **里面的数据是编造的示意。** 六个示例项目、示例账目、示例店铺、示例订阅，都一眼能看出是假的，方便你照着换成自己的。下面标「示意」的页面都是这个意思。
3. **手机端只给骨架。** iPhone、iPad 客户端给的是工程结构和搭建说明，不是签好名的安装包。你用自己的苹果开发者账号自己签名。

另外，标「接你自己的」的功能需要你配置自己的数据源，比如日历、健康、Anki。仓库里没有留任何默认连接目标。

## 功能清单

### 首页 · 一屏看完今天

- 今日摘要、重要提醒，打开时按时间段问候一句。
- 未来两天的日程和今天的待办，直接从你的库里读。
- 事业、语言学习、训练三张摘要卡，只读展示，不用手填。
- 天气与灾害提醒（配置你自己所在的地点）。
- 金融简报和公开行情，置顶一张你正在啃的知识地图。

### 日程安排 · 今天做什么

- 今日事项按四象限排，中央那栏是「最近两天」（示意任务）。
- 全部项目待办按项目分组，一页看完所有在推的事。
- 月度路线图和周排期两种视角，主线可以临时隐藏。
- 赴约行程走系统日历，出发导航和取票这类页面都在（接你自己的日历）。
- 新品发售关注列表；分四栏的时间入口。

### 事业顺利 · 项目怎么样了

- 项目组合页，每个项目一张卡，卡上是当前状态摘要。
- 项目关系网，看清哪几件事在互相拖。
- 限时大作战：给一段时间内必须打完的事单开一栏。
- 待办支持 S / A / B / C 四级，改完写回项目自己的原件，不是只改看板。
- 产品功能 Wiki 树，可以在树上原地做验收记录。
- 规则总览：把你为自己定的工作规矩集中放一处。

### 聊天 · 和秘书一对一

- 网页右侧的一对一面板，两位公开秘书（银月、梅凝）可以随时切换，默认银月。
- 对话存档能新建、打开、改名、删除；关掉页面回来还在。
- 能发图片、音频和文件；回复可以中途停止或重来。
- 分段朗读带语速调节，也可以走混合实时语音。
- 口述输入带纠偏，可以自己维护常错词。
- 网页任何地方选中一段文字，都能直接问秘书。
- 日记模式：把一段对话按日记归档的机制。

### 身心健康 · 身体的账也要记

- 每周训练建议表、训练日志、体围记录（示意数据）。
- 肌群恢复图，从训练日志派生。
- 心理负荷、人生平衡、身心状态报告三页留白，等你自己的记录填进去。
- 支持从 Apple 健康导入，也能设自动同步（接你自己的健康数据）。

### 世界资讯 · 每天一次，看完就走

- 日本、金融、AI、游戏四栏；AI 和游戏还分「眼下」和「这周要盯」。
- 每天早上定时合成一条，选稿口味写在一份可改的规则文件里，你可以把「我是谁」改成自己。
- 每条能收藏或点不喜欢，偏好只存在你本机。
- 附金融日历、大事记和公开行情；日语学习者可以直接读当天的日语新闻。

### 语言学习 · 以日语为样板

- 单词接你自己的 Anki，早晨自动拍一次进度快照。
- 文法分句型、助词、变形、敬语、表达五支。
- 阅读走新闻和赏析两条路；生词能收进自己的收藏。
- 专项练习和错题练习的壳子已经搭好。
- 手机上用语音助手做口语教学的接法，写成了可复用的机制。
- 探索成就页记录你走到哪儿了。

### 专题研究 · 长期啃的东西

- 八个母题的知识地图；其中游戏和人工智能两张已经有完整骨架，其余留了版面和大纲。
- 点读知识卡：一句话一张卡，点开看解释。
- 想重点推进哪张地图，可以置顶到首页。
- 学习经历架：把已经上完的课按名字和日期排一排。

### 艺术馆藏 · 玩过看过读过的

- 游戏库、动漫馆藏、书架、写作四个架子（示意名单）。
- 任何 Markdown 都能在站内全文阅读。

### 资产管理 · 钱的全景

- 总览、投资分析、收入、支出四页，配一套一千万的虚构演示账。
- 账单可以按格式导入。
- 这几页可以单独上锁，做成需要另开授权才进得去的私有入口。
- 支付资金守卫：扣款前先提醒一句。

### 实用工具 · 一排杂活

- **协作记录**：工作日志、对话日志、会议纪要、技术讨论四类，各带一篇示意样稿。
- **秘书收件箱**：照片、书签、项目收件、回收站四个同级标签。来件能复制、删进回收站、单条复原或全部清掉。iPhone／iPad 可以把原图存进相册或文件；Mac 不显示保存图片。默认是空的。
- **设计台**：一块画布，用来画三端界面示意。
- **工具与素材收藏、网页收藏、美食地图、支付与续约**：四个轻量清单页，各放了少量编造条目。
- **异常雷达**：定时任务出问题时在这里看（默认没有实况，不伪造成败）。
- **Token 管理**：模型用量看板，缓存、自身、子任务分色（默认没有历史账）。
- **项目素材库**：素材按用途索引，分正式、候选、归档三档浏览整理。
- **游戏数据表现**：给自己做的游戏留的经营看板壳。
- **音乐、视频、相册**：三个空壳播放器，指向你自己的目录才有内容，默认什么都不读。
- **系统设置**：外观、字号、快捷键、值班秘书。
- **关灯模式**：一键把副屏遮黑、主屏压到微光，只作用于跑工作台这台 Mac。
- **常亮模式**：临时不让电脑睡，关掉即恢复。

### 全局 · 用起来顺不顺手

- 玄夜、晴岚两套主题。
- 顶栏层级导航，⌘1—6 直接跳分区，支持前进后退。
- 侧栏可收起，能把常去的页面做成书签。
- 每台设备各自记住上次停在哪一页。
- 手机上能看完整的 Mac 版视图；iPad 上切页稳定。

### 定时与自动化

- 服务自己的持续监控，掉了会有反应。
- 每日轻量检查、每周版本收口，各是一条可以自己跑的流水线。
- AI 自动验收的机制：让 AI 按清单跑一遍，再把结果写回记录。
- 金融简报、世界资讯简报、日评周报月报，都是定时任务加模板。

### 数据与安全

- 读文件走白名单，路径越界直接拒绝。
- 写文件先出预览，确认了才落盘；路径冲突有保护。
- 想远程用可以自己接私人网络（比如 Tailscale），仓库不带任何默认入口。
- 凭据不进仓库；备份和恢复写了方法，不写具体拓扑。

### 多端与外围

- **Mac 桌面壳**：一个浮动入口加工作台窗口，支持副屏全屏，源码是 Swift。
- **iPhone / iPad 一对一客户端**：工程骨架和搭建说明。界面上有「视频感」（说话时头像固定居中、字幕单独滚动）、已读与已读不回、发送失败重试、草稿恢复、行动确认这些通用件。
- **系统分享扩展**：在手机任何 App 里选「发给秘书」，把网页、文字或图片投进收件箱。
- **Chrome 扩展**：网页上右键「发给秘书」；另有一个划词提问的小扩展。
- **只读 MCP**：让别的 AI 工具只读地翻你的库，库根由你自己配置。

### 给 AI 协作者准备的

仓库根有一份 `AGENTS.md`，另带三条短规则：任务标题用中文、待办按 S/A/B/C 分级、说人话。Cursor 打开仓库根时会自动加载 `.cursor/rules/`；用 ChatGPT、Codex 或其他 Agent 时，直接读 `AGENTS.md` 即可。

目前作者更推荐用 **GPT 6 mini** 做本项目的首次搭建。工作台聊天默认不绑定任何一家工具，接哪套 Agent 由你自己改适配。

## 技术形态

- 前端 React 19 + TypeScript + Vite；后端是一个 Node 22 的本地服务，没有数据库，数据就是文件。
- 包管理用 pnpm，lockfile 已锁版本。
- 桌面壳和手机端是 Swift / SwiftUI；浏览器扩展是 Chrome MV3。
- 服务默认只听 `127.0.0.1:5173`。

## 上手

1. 装好 Node.js 22 和 lockfile 对应版本的 pnpm。
2. 在 `Infans_Studio/00_本地工作台/app` 跑 `pnpm install --frozen-lockfile`。
3. 建数据根：`pnpm init:data`（默认建在你家目录下一个新文件夹；也可以用环境变量指到你想放的空目录）。已经有库了就改用 `pnpm bind:data`，它只写指针，不动你的文件。
4. `pnpm build`，再跑 `scripts/start-local.sh`。
5. 浏览器打开 `http://127.0.0.1:5173`。

**不要把仓库本身当数据根。** 聊天存档、缓存、运行记录都应该落在源码之外。

首次搭建时，目前作者更推荐用 GPT 6 mini 对照 `AGENTS.md` 和 `docs/quickstart.md` 往下走。

详细说明看 `docs/`：`quickstart.md`（上手与常见错误）、`capabilities.md`（每项能力现在到什么程度）、`ios-build.md`（手机端怎么搭）、`macos-build.md`、`self-hosting.md`（离线时先接件的中转信箱）、`backup-and-restore.md`、`workstation-screens.md`（多屏怎么摆）。

## 隐私

这套东西本来是给一个人自用的，所以隐私是按「默认不出门」设计的：服务只听回环地址，读写都在你自己指定的目录里，没有账号系统，没有遥测。公开仓库里的示例数据全是编造的，你不会在里面看到任何真人的日程、账目或聊天。
