# 手机快速收件

链路：系统分享或 Chrome → 设备持久队列（同一稳定 ID）→ 直连本机或经自托管信箱 → Mac 原子保存 → `mac_persisted` 回执。

直连是否可用以当前协议实现为准。未配置信箱时不得回连任何作者主机。公开示例图只用原创 SVG 占位。

iOS Share Extension 与 Chrome「发给秘书」扩展源码随候选提供。现行扩展目录只有 `chrome-extension-发给秘书`。对外按钮文案是「发给秘书」，接口为 `/api/inbox`。收件箱有照片、书签、文件、项目收件、回收站五个标签，默认是空的。手机可以保存图片或文件；Mac 没有保存按钮。电脑复制文件走系统剪贴板：粘贴进对话是正文，粘贴到访达是文件。无后缀的文件路径也能进箱。回收站可单条复原或全部清理。工作台里划字后可以直接问秘书，不依赖浏览器扩展。
