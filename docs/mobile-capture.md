# 手机快速收件

链路：系统分享或 Chrome → 设备持久队列（同一稳定 ID）→ 直连本机或经自托管信箱 → Mac 原子保存 → `mac_persisted` 回执。

直连是否可用以当前协议实现为准。未配置信箱时不得回连任何作者主机。公开示例图只用原创 SVG 占位。

iOS Share Extension 与 Chrome 扩展源码随候选提供。现行扩展目录是 `chrome-extension-发给秘书`、`chrome-extension-问问小秘书`。对外按钮文案是「发给秘书」，接口为 `/api/inbox`。Mac 工具页已保存来件可复制到剪贴板或删除进回收站；照片复制成较小 JPEG，不复制原图格式。iPhone／iPad 打开同一收件箱时，可以把原图存进系统面板（存储到照片或存储到文件）；Mac 不显示保存图片。回收站可单条复原或全部清理。
