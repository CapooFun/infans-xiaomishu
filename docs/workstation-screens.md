# 工作台屏幕怎么摆

这是一份给使用者的参考，不是必须照做的规格。界面本身已经按宽屏优先、同时兼容 Mac、iPad 和 iPhone。你有几块屏、怎么连，按自己的桌子来。

## 常见组合

长期够用的组合是：**一台电脑外接两块显示屏**。如果再加上电脑自己的屏幕，以及一块用 Wi‑Fi 打开工作台的平板，日常就可能同时看着四块屏。

不必把每块屏焊死成固定用途。可以同时开着，看当时在做什么。下面只是一种比较省脖子的摆法：

| 位置 | 可以优先放什么 |
|---|---|
| 左边那块大屏 | 小秘书工作台 |
| 右边那块大屏 | 正在对话的编程助手或 GPT；如果还有第二台电脑，平时也可以走这块屏，偶尔两块大屏一起用 |
| 电脑自己的屏幕（多在左下方） | 临时窗口、正在改的编辑器 |
| 大屏下方的平板 | 用 Wi‑Fi 打开工作台扫一眼；偶尔处理聊天、确认一类短操作。平板不必接到电脑上做镜像 |

平板用浏览器或主屏幕网页打开工作台即可，不一定要用系统隔空播放。宽屏上正文应有可读上限，不要一行拉到屏幕两边；手机上再收成单栏。

## 请自己补一张桌子照片

建议在自己的库里放一张工位照片，让以后帮你改界面的 AI 能看见几块屏、哪块在左边。照片是你自己的参考，不要把别人家里的桌子图拷进这个仓库。

改界面时请同时检查：很宽的桌面、普通笔记本窗口、平板横屏、手机竖屏。平板横屏是大屏触控的第一选择；手机先保证单手能用。
