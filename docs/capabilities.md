# 公开能力矩阵（候选）

状态只描述本轮本地候选，不是发布声明。开源秘书是银月、梅凝，可切换；默认银月。对外收件动作名为「发给秘书」。

| 能力 | 状态 | 说明 |
|---|---|---|
| 工作台浏览与虚构待办 | 已在隔离环境验证 | `/api/health` 与 `/api/project-management` 读到六个示例项目 |
| 银月、梅凝单聊与「我」用户 | 参考实现 | 两位公开工作秘书可切换，默认银月；公开设定独立编写；称用户「你」。工作台里划字后可以直接问秘书 |
| 收件队列与信箱 | 参考实现 | 设备投递 API 为 `/api/inbox`；工具页读取为 `/api/tools/inbox`。收件分类是照片、书签、文件、项目收件、回收站五个同级标签；默认是空的，不带示例来件。可复制、删除进回收站、单条复原或全部清理；电脑复制文件走系统剪贴板（文本文档同时带正文和原文件名）；手机可保存图片或文件，Mac 没有保存按钮；默认信箱 URL 已清空；现行 Chrome 扩展只有 `chrome-extension-发给秘书` |
| Mac 成品包 | 需自行适配 | 现有脚本依赖已安装 App 与宠物素材，不是通用成品入口 |
| iOS / 分享扩展 | 只留架构 | 步骤见 `docs/ios-build.md`：用一线 AI 按工程骨架自己还原、自己申请苹果开发者账号、自己填 Team／Bundle ID／App Group、自己签名。仓库空位是 `com.example.infans.secretary*`，Team 为空 |
| 原生一对一聊天界面 | 参考实现 | 视频感把头像固定在画面中央，字幕单独滚动；会话列表头像右上角有未读红点。已读／已读不回。发送失败可重试 |

| 快捷键 | 使用者自己的 Mac | 系统设置里可改关灯、截屏、截进当前 Agent 对话、秘书朗读和听写。关灯默认 Command+Esc。保存写进使用者自己的 Mac 和当前 Agent 工具；桌面壳读取同一接口。现成适配仍按常见桌面 Agent 键位，可自己改 |
| 关灯模式 | 已同步 | 切断副屏信号 + 内屏微光；只作用于运行工作台的这台 Mac |
