# Mac 从零构建

当前私有打包脚本会读取已安装的 `.app`、私人宠物视频和本机签名身份，**不能**当作开源版的通用入口。

## 源码路线（本轮保底）

1. 安装已验证的 Node.js 与 pnpm。
2. 设置 `INFANS_VAULT_ROOT` 为示例库或你自己的数据目录。
3. 在 `Infans_Studio/00_本地工作台/app` 执行 `pnpm install --frozen-lockfile`、`pnpm build`、`INFANS_PORT=5173 pnpm start`。
4. 只监听 `127.0.0.1`。远程访问需要你自己配置的可信代理，没有作者主机默认值。

Swift 外壳源码在 `app/native/SecretaryApp.swift`。默认构建不得替换你已经安装的应用。

## 成品包（有条件）

若只要封装 Node 运行环境、生产依赖和启动脚本，可在后续迭代做便携启动包。若必须更换桌面框架、建立自动更新或长期公证签名，则成品包降为后续项，不阻塞源码公开。

宠物视频是可选能力；默认构建不应依赖私人宠物素材。
