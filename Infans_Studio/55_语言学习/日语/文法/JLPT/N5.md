# N5 文法示意

创建：2026-08-20　最近修订：2026-08-20
用途：开源示例。只有几条人人都学的句式，用来撑起文法看板和专项练习。
掌握度是编的。

## 一、判断与基本句型

**N5-01 〜は〜です**　｜掌握度 3｜复习 2026-08-20
- 接续：N ＋ は ＋ N ＋ です
- 含义：A 是 B（断定）
- 例：私は学生です。我是学生。

**N5-02 〜は〜ではありません**　｜掌握度 2｜复习 2026-08-20
- 接续：N ＋ は ＋ N ＋ ではありません
- 含义：A 不是 B
- 例：これは本ではありません。这不是书。

**N5-03 〜でした**　｜掌握度 2｜复习 2026-08-20
- 接续：N ＋ でした
- 含义：过去的断定
- 例：昨日は休みでした。昨天是休息日。

**N5-04 〜か（疑问）**　｜掌握度 2｜复习 2026-08-20
- 接续：句尾 ＋ か
- 含义：构成疑问句
- 例：あなたは先生ですか。你是老师吗。

## 二、助词与存在

**N5-05 〜も**　｜掌握度 2｜复习 2026-08-20
- 接续：N ＋ も
- 含义：也…
- 例：私も行きます。我也去。

**N5-06 〜の（领属）**　｜掌握度 2｜复习 2026-08-20
- 接续：N ＋ の ＋ N
- 含义：…的
- 例：私の本。我的书。

**N5-07 〜と（并列）**　｜掌握度 2｜复习 2026-08-20
- 接续：N ＋ と ＋ N
- 含义：和…
- 例：パンと牛乳を買う。买面包和牛奶。

**N5-08 〜があります／います**　｜掌握度 1｜复习 2026-08-20
- 接续：场所 に ＋ N が あります／います
- 含义：有（物／人）
- 例：机の上に本があります。桌上有书。
