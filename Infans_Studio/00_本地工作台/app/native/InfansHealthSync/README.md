# Infans Health Sync（开源候选）

iPhone／iPad 一对一客户端与系统分享扩展的**基本架构**。把来件送到你配置的信箱或本机工作台。

这不是作者已经签好的安装包，也没有预置能连上作者机器的默认地址。

使用前请换成你自己的 Bundle ID、App Group、Team ID 和签名身份。仓库里如果还看得到作者签证号，那是施工残留，必须改成你自己的，不能当交付物。

**Watch 不开源。** 手表 App、表盘和 Watch scheme 已从本工程拿掉。iPhone 里若还留着 WatchConnectivity 空桥，只是为了主 App 能编过，不是开源产品能力，也不要往手表上装 Infans 开源包。

Mac 成品包不随本候选提供。
